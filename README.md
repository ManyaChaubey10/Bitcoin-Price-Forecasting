## Jira Development Integration

This repository is being used to demonstrate Jira–GitHub integration for the HealthTracker App project.

- Jira issue: HTA-3 — Requirements Gathering
- Purpose: Track development work through a branch, commit, and pull request.
- Verification: Changes should be reviewed before merging.

## Jira Story HTA-4 — UI/UX Design

This section documents the UI/UX Design work item for the HealthTracker App Jira integration demonstration.

- **Jira issue:** HTA-4 — UI/UX Design
- **Purpose:** Track design-related work using a Jira-linked GitHub branch and pull request.
- **Workflow:** Create a branch, commit the documentation update, open a pull request, and merge it after review.
